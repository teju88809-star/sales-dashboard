# Sales Dashboard

An interactive Power BI dashboard built with the Global Superstore dataset. It helps viewers explore sales performance by month, region, and product category.

## Project contents

- `sales_dashboard.pbix` — Power BI dashboard
- `Sales_Dashboard_Guide.pdf` — one-page guide to reading the dashboard

## Dashboard features

- KPI cards for total sales, total profit, and quantity sold
- Sales charts by month, region, and product category
- Month and region slicers for interactive filtering

## How to use

1. Download the `.pbix` file from this repository.
2. Open it with Power BI Desktop.
3. Use the Month and Region slicers to filter the dashboard.
4. Refer to the PDF guide for an explanation of the KPIs and charts.

## Data

The dashboard uses the Global Superstore dataset. The dataset is not included in this repository. If Power BI asks for the source file, reconnect it to your local copy of the dataset and refresh the report.
